# Stocker les médias sur Cloudflare R2

Avec R2, le navigateur envoie les fichiers directement à Cloudflare, et les réseaux
sociaux les téléchargent par une adresse publique. C'est obligatoire pour Instagram,
TikTok et Facebook.

## 1. Créer le bucket

Dans le tableau de bord Cloudflare : **R2 > Create bucket**. Nom au choix, par exemple
`cadence-media`.

## 2. Le rendre accessible publiquement

Dans le bucket : **Settings > Public access**. Deux possibilités :

- **Custom Domain** (recommandé) : un sous-domaine d'un domaine géré par Cloudflare,
  par exemple `media.tondomaine.com`. C'est la seule option compatible avec TikTok,
  qui exige de vérifier le domaine d'où viennent les médias.
- **R2.dev subdomain** : une adresse `pub-xxxx.r2.dev` fournie par Cloudflare. Rapide
  à activer, mais limitée en débit et prévue pour les essais.

L'adresse obtenue est la valeur de `R2_PUBLIC_BASE_URL`, sans slash final.

## 3. Autoriser l'envoi depuis le front (CORS)

Dans le bucket : **Settings > CORS Policy**, colle ceci en remplaçant l'adresse par
celle de ton front :

```json
[
  {
    "AllowedOrigins": ["https://ton-projet.vercel.app"],
    "AllowedMethods": ["PUT"],
    "AllowedHeaders": ["Content-Type"],
    "MaxAgeSeconds": 3600
  }
]
```

Sans cette règle, l'import d'un média échoue dans le navigateur.

## 4. Créer les identifiants d'accès

Sur la page **R2** : **Manage R2 API Tokens > Create API Token**.

- Permissions : **Object Read & Write**
- Limite-le au bucket créé à l'étape 1.

Cloudflare affiche alors un **Access Key ID** et un **Secret Access Key** (une seule
fois : note-les). L'**Account ID** est indiqué sur la page d'accueil de R2.

## 5. Variables à définir sur le service de l'API

| Variable | Valeur |
|---|---|
| `STORAGE_BACKEND` | `r2` |
| `R2_ACCOUNT_ID` | l'Account ID Cloudflare |
| `R2_ACCESS_KEY_ID` | l'Access Key ID de l'étape 4 |
| `R2_SECRET_ACCESS_KEY` | le Secret Access Key de l'étape 4 |
| `R2_BUCKET` | le nom du bucket |
| `R2_PUBLIC_BASE_URL` | l'adresse publique de l'étape 2 |

## Vérifier

Dans l'app, importe une image dans **Médias** : elle doit s'afficher, et son adresse
doit commencer par `R2_PUBLIC_BASE_URL`.

Les médias importés avant le passage à R2 restent dans l'ancien stockage et ne sont
pas copiés : réimporte ceux dont tu as besoin.
